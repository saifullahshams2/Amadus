### ⏱️ TIMATIC (Travel Information)
In Amadeus Selling Platform, follow these steps:
1. Verify you are in the command page or click on the command page icon.
2. Click on the **Scripts tab**.
3. The information icon on the extreme right under the Scripts tab refers to Timatic. Use a mouseover to confirm.
4. Click on the icon. This opens the Timatic window (Visa/Health/Customs/Taxes info).
5. To email this info, click the FAX/Email icon and then **Send**. Enter the receiver's email address.

**Cryptic Commands:**

## 🌟 ACCESS LEVEL EXPLANATION

| Indicator | Level | Description |
| :--- | :--- | :--- |
| **(/)** | **Amadeus Complete Access** | Highest connectivity; last-seat availability & immediate confirmation. (e.g., BA, AF). Can still use ACL or 1XXad entry if not Altea airline. |
| **(.)** | **Amadeus Access Sell** | Fully secured sale per seat. Checks inventory immediately. Returns HK (Confirmed), UC/HL (Waitlisted/Rejected). Airline's locator appended after EOT. |
| **(\*)** | **Direct Access (DIR)** | Real-time link to airline system for accurate availability. Seats sold carry **LK** status code. Sell within 3 minutes of accessing the display. |
| **( )** | **Standard Access** | Schedules updated weekly. Confirmation/rejection within 12 hours. Seats sold in **SS** status code. |
| **(-) ** | **Amadeus Ticketless Access** | Enables availability/schedules from LCCs in principal displays. Identified by 'Y' on GG PCA page. (e.g., AK) |

> **➡️ Slash Indicator (/):** Indicates seat count is obtained in real-time from the airline’s inventory (True number of seats left). *Example: `MK, QF, SA, VS`*

## 📜 GENERAL DOS AND DONTS FOR RESERVATIONS (Summary)

1.  **DO NOT** use fictitious names or speculative segments to block space.
2.  **ENSURE** passenger names are identical to travel documents/passports (complete first names).
3.  **DO NOT** cancel HL segment and rebook as HK in one transaction (may cause rejection).
4.  **DO NOT** cancel/rebook solely to extend airline's time limit (system abuse).
5.  **DO NOT** override MCT warnings at EOT.
6.  **DELETE (DL)** rather than **CANCEL (XE)** all inactive segments ($\text{HX}/\text{NO}/\text{UC}/\text{UN}$).
7.  **ALWAYS** advise TKT time limits via OSI message.
8.  **DO NOT** insert duplicate ticket numbers in SSR/OSI if FA/FH exists.
